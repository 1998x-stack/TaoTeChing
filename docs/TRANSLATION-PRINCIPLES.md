# Translation Principles · 白话意译编写规范

## 目的

用现代中文降低古文阅读门槛，同时尽最大可能保存老子的论证结构、比喻和模糊性。允许解释，但必须承认解释并不等于原典唯一字义。

## 翻译分层

1. **经文 (Original)：** 可溯源的古文，不混入译者理解。
2. **直译 (Literal，未来字段)：** 与句子形态尽量一一对应，保留语义歧义。
3. **意译 (Paraphrase，V1 已有)：** 用自然中文说明章节主要论旨，允许合并句子，必须标明「白话意译」。
4. **注释 (Annotation，未来字段)：** 对古代器物、语词义项、哲学或政治背景补充来源。
5. **现代阐释 (Modern reflection)：** 可讨论现实启发，但不得写成「老子已经证明」。

## 八条规则

- 原文和译文**必须就近显示**。当前同章双栏/手机上下，未来实现逐句对照。
- 不随意删掉重要的逻辑转折与相反相成结构。
- 「道」「德」「无为」「玄」「自然」「有」「无」不机械等同于现代术语。
- 遇到古人社会观念，如「愚民」「小国寡民」，直译与现代评价分离。
- 「刍狗」不能简单解释为鼓励残酷；需区分天道无私的解释传统和其他读法。
- 「无为」不应粗暴写成「什么都不做」；也不能泛化为放任不管。
- 不引入现代名人名言来冒充古代译文，不复制受版权保护的现代译本。
- 不确定之处保持标记，并在注释中列出至少一种替代理解。

## 样例：第一章

原文：道可道，非常道。
直译：能够说出的道，并非恒常之道。
意译：可以通过言语描述的道，并不能穷尽那永恒的根本规律。
注释：涉及「道」作为道路、方式、言说和根本原则等层次；「常/恒」还需联系避讳与早期异文。

## 必要编辑检查

读者能否找到对应原句？章节是否完整？含糊处是否被不恰当地定论？是否把译者推测写成史实？是否有明确底本标识？答不出上述问题时，标注 needs-review，不予宣称定稿。
