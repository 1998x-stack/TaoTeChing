# QA Plan · 内容与功能验收

## 自动化（当前）

入口：npm test → node --check app.js / data/chapters.js + scripts/validate.mjs。

覆盖范围：
- 共 81 章，编号 1..81 唯一连续；
- 道经 37 章、德经 44 章；
- 每章都有原文、意译、标题与有效主题；
- 506句手工译文与分句数量完全匹配，重新拼接原文逐字无损；
- 首章与末章关键句存在；
- HTML 必备 DOM 节点存在且不重复；
- App 引用相关节点，避免 innerHTML 注入路径；
- 必需源文件和工作流存在。

**不能声称覆盖：** 古籍逐字对照、实际浏览器布局、真实复制权限、屏幕阅读器、性能测试或 Pages 在线部署。

## 发布分级

- **P0 阻断：** 章节缺失、浏览器报错、原译内容为空、Pages 404。
- **P1 高优先：** 原文校勘不实、错误文字、深链失效、手机布局溢出。
- **P2 中优先：** 收藏丢失、动效不流畅、对比度不足。
- **P3 低优先：** 视觉微调、非核心装饰。
