# Design System · 玄墨 / Ink & Parchment

## 创作方向

**不是仿古网页，而是以现代数字美学讲述传统哲学。** 设计借鉴高端硬件发布页的叙事密度、滚动节奏、微动效与留白；造型和材料语言则来自山水、日月、宣纸、篆刻与竹简。

### 设计关键词

深墨 / 宣纸 / 金石 / 负空间 / 山水层叠 / 缓慢的运动 / 一眼可读 / 逐步揭示。

### 设计准则

1. **文字是主角。** 首页可以具有视觉张力，进入阅读室后保持极低的视觉噪声。
2. **相反而互成。** 深色似夜读之墨，浅色似宣纸留白；二者具有相同的布局与信息层次。
3. **动效节制。** 光晕呼吸、太阳微浮、山峦入场、元素揭示，均不承载关键信息。
4. **古今并置。** 中文宋体用于经典与标题，系统无衬线用于导航、元数据与控件。

## 页面编排

**Act I / 道：** 满屏主视觉。超大「道德经」、简短引句、环形日轮、渐层山势，强烈的第一印象。

**Act II / 观：** 三个哲学命题的卡片结构，让「自然 / 平衡 / 不争」成为可导航的入口。

**Act III / 静：** 第十六章的单句休止符，将滚动节奏从高张力降到宁静。

**Act IV / 藏：** 81 章的目录网格，搜索与主题分类成为探索入口。

**Act V / 读：** 阅读室：侧栏章节、双列原译、字号与模式、导航、书签，弱化动效。

## 动画

- 太阳缓慢漂浮（9s ease-in-out），光晕呼吸（9s）。
- 山峦自下渐显，制造水墨层次，但不构成主要文字内容。
- 区块进入视口后渐入 0.8s。
- hover 采用背景与边框渐变，不依靠巨大位移。
- 尊重 prefers-reduced-motion: reduce，取消所有动画。

## 响应式

Desktop ≥1100px：3列概念卡、4列章节卡、双列原译、常驻阅读目录。

Tablet 761–1099px：3列章节、收窄阅读侧栏和间距。

Mobile ≤760px：单屏 hero、2列章节卡、可横向滚动的章目录、原译上下堆叠。极窄屏进一步收紧排版。

## 状态与可用性

必须保留明显的焦点环、操作按钮文本、空结果提示、禁用状态与复制反馈。颜色不作为状态的唯一信号。
