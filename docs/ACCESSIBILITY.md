# Accessibility · 可访问性规范

## 目标

以 WCAG 2.2 AA 的精神设计阅读体验；当前实现提供基本可访问性，不声称已经通过完整的 WCAG 审计。

### 已提供

- 语义分区：header / nav / main / section / article / aside / footer。
- 键盘操作：Tab 与 Enter 使用原生按钮；/ 键聚焦搜索；左右方向键切换章节（焦点不在输入框时）。
- 跳转链接：页面顶部提供「跳至正文」。
- 可见焦点：交互元素在 focus-visible 下显示强调环。
- 字号：阅读室 16px–28px 的用户控制。
- 动效：prefers-reduced-motion 会关闭装饰性动画。
- 状态：搜索结果数通过 role=status 宣告；收藏使用 aria-pressed；章节切换有文本。
- 逐句遮译：每句译文使用 hidden 真隐藏，按钮使用 aria-expanded 和 aria-controls 指向同句译文，不只用模糊或透明遮挡。
- 纯 CSS 山水为装饰，不承载关键信息。

### 待改进

- 做自动对比度扫描与屏幕阅读器手测。
- 阅读室切换章节后提供更明确的焦点管理与实时朗读提示，避免上下文变化不被察觉。
- 键盘箭头可能与用户预期的滚动方式冲突，后续提供快捷键开关。
- 部分浅色与深色次要文字对比度需要正式色彩比计算核验。
- 增加打印样式及可访问语音阅读模式（音频必须有授权）。

## 手工测试流程

1. 用键盘从页面顶部依次 Tab，确认顺序和焦点可见。
2. 不用鼠标完成搜索、打开章节、逐句揭晓和收起译文、收藏、下一章。
3. 手机 320px/375px/430px 宽度下确认正文不横向溢出。
4. 开启系统「减少动态效果」，确认所有装饰动画停止。
5. 用至少一种屏幕阅读器验证搜索结果数、章节标题、按钮状态和复制反馈。
6. 浏览器放大到 200% 仍保留可阅读性。
