# Philosophy Atlas · 哲学关系可视化构想

## 核心问题

《道德经》不是 81 条彼此孤立的格言。它有围绕「道」「德」「自然」「有无」「柔弱」「不争」「知足」的思想网络。下一阶段以可核实的经文关系为基础，绘制交互式概念星图。

## 建议的本体模型

节点类型：
- Chapter / Passage：章与句，具有稳定 id 和文本来源。
- Concept：道、德、自然、柔、静、虚、无、有、朴、知足、不争。
- Metaphor：水、谷、婴儿、车毂、弓、江海、烹小鲜。
- Claim：显式论点与条件性论证。
- Edition：见证文本及修订坐标。

边类型：
- EXEMPLIFIES（比喻说明），如水→不争。
- DISCUSSES（涉及），如第八章→柔弱与不争。
- CONTRASTS_WITH（形成对照），如有↔无。
- BUILDS_ON（构成论证递进）。
- VARIANT_OF（版本对应，必须保留来源）。
- INTERPRETED_AS（译法/释义关系，必须记录争议）。

## 数据可信度

每条关系应包含 sourceChapter、sourcePassage、evidenceText、editor、status、confidence。由语言模型生成的关系默认 draft，需要人工复核。概念图不是经文本身，必须把解释性关系和明确引文区别展示。

## 交互体验

首页可用山峦、流水与日轮隐喻图谱层级；进入研究模式后，以简约力导图 / 环形图浏览不同概念，从概念点击到句子，再回到原译对照阅读室。

**优先级：** 先解决精确逐句对齐与版本来源，再开发华丽图谱；不应以视觉连线掩盖缺乏证据的解释。
