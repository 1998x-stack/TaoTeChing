# Roadmap · 分阶段实施

阶段定义按可验收结果，而不是仅按界面完工描述。未通过验收不得写成已完成。

## Stage 0 · Repository Foundation

- [x] 初始化 GitHub repository 的 main 分支
- [x] 81 章数据模型和基础自动检测
- [x] README / CONTRIBUTING / 许可证说明
- [x] CI 和 Pages 的声明式 workflow
- [ ] 确认 CI 全部通过，网站实际可访问

**验收：** 文件齐全，npm test 通过，GitHub Actions 的结果为 success。

## Stage 1 · Immersive Reader (V1)

- [x] 墨色与宣纸双主题 / 视觉设计系统
- [x] CSS 动画山水 hero / 响应式网格
- [x] 道经与德经导航 / 章节深链
- [x] 章级原文与白话意译对照
- [x] 搜索、主题、书签、字号、本地上次阅读
- [ ] 浏览器实际交互、移动端、无障碍手动验收
- [ ] 正式 Pages 发布 URL 验证

**验收：** 桌面和手机都可读完 81 章，关键流程通过 QA-PLAN。

## Stage 2 · Scholarly Edition (V1.1)

- [ ] 明确唯一版本底本和固定 revision / 书目
- [ ] 与底本逐章逐字比对、修复异文混用
- [ ] 每章原文拆为稳定 passageId，逐句翻译并注释
- [ ] 争议译法标记与可展开解释
- [ ] 多人审阅流水线与文本变更日志
- [ ] 版本差异视图（王弼 / 帛书 / 郭店的对应片段）

**验收：** 所有经文字句可回溯来源；逐句对齐正确；未覆盖的版本差异明确可见。

## Stage 3 · Philosophy Atlas (V1.2)

- [ ] 定义概念 Ontology：道、德、无、有、柔、静、自然、不争
- [ ] 将章节与概念、比喻和论证关系编码成图谱
- [ ] 提供交互式概念漫游，点击边可以回到精确章句
- [ ] 添加证据级别和解释来源，避免 AI 生成幻觉
- [ ] 增加传统字形和导出功能

**验收：** 每条可视化连线都能回溯到经文及解释依据。

## Stage 4 · Research Platform (V2)

- [ ] 多版本校勘视图与古文字资料索引
- [ ] 搜索词规范化及高亮，学习进度导出
- [ ] 可选离线 PWA、诗意主题生成器
- [ ] 支持教学讲义和研究引用格式

**验收：** 可重复验证内容准确性、性能和可访问性，不牺牲静态托管的简洁性。
