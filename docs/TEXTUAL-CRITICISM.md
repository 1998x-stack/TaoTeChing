# Textual Criticism · 底本、异文与文献规范

## 强制说明

本项目当前是**按王弼本通行章序编排的简体阅读文本**，**尚未完成与某一固定底本逐字、逐句的完整校勘**。页面不能声称这是「王弼亲定原本」「最早版本」「唯一标准译文」或「学术定本」。

使用现代标点、简化汉字和编辑性章题。页面白话意译由本项目重新写作，可能省略字词层面的多种解释，因此不能当成逐句对应的学术翻译。

## 可核对的主要文献入口

1. [维基文库《道德经（王弼本）》](https://zh.wikisource.org/wiki/道德經_(王弼本)) — 王弼传世注本的一种线上整理录文，经文与注文并存，校对时必须区分。
2. [中国哲学书电子化计划《道德经》](https://ctext.org/dao-de-jing/zh) — 便于查阅章次、检索读本。
3. [维基文库修订历史](https://zh.wikisource.org/w/index.php?title=道德經_(王弼本)&action=history) — 钉住具体 revision ID 后才能复现实验。
4. [郭店与马王堆版本概览](https://dao-de-jing.com/zh/manuscripts) — 版本关系线索；以公开出版物与一手整理本进一步核实。

## 重要版本差异

| 文献系统 | 事实提醒 | 编辑规则 |
| --- | --- | --- |
| 传世王弼本 | 通行「道经→德经」81 章 | V1 使用其章序作阅读坐标 |
| 马王堆帛书甲、乙本 | 「德篇→道篇」的排列，不少用字与通行本不同 | 只能作为明确标注的异文列，不直接覆盖 |
| 郭店楚简《老子》 | 保存的是部分材料，不是完整 81 章的逐字早本 | 无对应简文时须标注「无对应」，不得补造 |
| 河上公本 | 与王弼文本及解释传统可能存在差异 | 注明注本后再比较 |
| 北大汉简 | 另有章数和篇序特征 | 需独立建立章次映射 |

### 已知高风险校勘点

- 第 1 章「常」与早期帛书中的「恒」等异文。
- 第 17/18/19 章部分章句分合与断句。
- 第 38 章在通行篇序中是德经开头，而帛书整体篇序相反。
- 第 41 章「大器晚成」存在其他传本写法；不得只凭熟语修订古本。
- 第 64 章「九层之台」「千里之行」与竹简、帛书对应文字的异同。
- 第 65 章「愚之」带有政治思想争议；不可直接美化为现代教育观。
- 第 81 章「知者不博」应保留语境，避免断章当作反知识论。

## 必须执行的审校工序

1. **固定基准：** 选定来源、精确 revision 或出版书目信息，记录访问日期与处理规则。
2. **分离层级：** 原典文字、标点、现代简繁转换、编辑性标题、译文和导读分别维护。
3. **逐章比对：** 检查增删、异体、避讳、句读。记录原字、采用字和依据。
4. **异文单列：** 未核实的读法不得混入正文；只保留为待核异文。
5. **双人复核：** 至少一人录入、一人独立校对；争议交由有古汉语阅读能力者复查。
6. **变更可追溯：** PR 标注章号、旧读、新读、来源与版本号，必要时提供截图或影印页码。
7. **发布标记：** 只有完成校勘清单的章节才能标记为 reviewed。

## 使用许可

老子古代原作属公有领域，但具体近现代整理成果、译文、注释及扫描图片可能另有权利要求。避免整段复制现代译文；新意译应独立撰写，合理引用并明确来源。
